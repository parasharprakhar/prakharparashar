# Scripted VocabPro portfolio demo

## Goal
Replace the external VocabPro preview with a polished, self-contained product demo inside the existing Featured Project section.

## Experience
- Start with a clearly labelled Demo Mode sign-in flow using pre-filled fictional credentials: email first, then masked password, then sign-in.
- Transition into a compact VocabPro interface styled from the verified public build, with Home, Teams, Learn, Play, and VocabBot navigation.
- Make every destination functional and populate it only with explicitly fictional vocabulary, people, progress, and game data.
- Build focused Home, Teams, Learn, Play, and VocabBot views rather than reproducing the full external application.
- Give VocabBot exactly two preset questions, no free-text field, with scripted answers and a working Get VocabPro action.
- Keep the existing Featured Project copy unchanged and remove the external iframe/screenshot behavior.

## Quality
- Keep the demo within the existing device frame, accessible by keyboard, responsive on mobile, and visually coherent in both portfolio themes.
- Preserve all previously completed links, programme interactions, animations, count-ups, and the automation pipeline.
- Verify the full login sequence, every demo tab, both bot responses, reset behavior, mobile layout, and clean build.
